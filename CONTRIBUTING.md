# Contributing

Спасибо за интерес к AICOACH. Проект небольшой и намеренно простой — правки ценятся
хирургические: минимум кода, который решает задачу, без абстракций «на будущее».

## С чего начать

1. Разверни локально по [README → Быстрый старт](README.md#быстрый-старт).
2. Прочитай [README → Архитектура](README.md#архитектура) — это «голый мозг» (один LLM
   с tool-loop) плюс файловая память, а не жёсткий пайплайн. Держи эту модель в голове.
3. Открой [issue](https://github.com/denimasterden-ui/personal-ai-coach/issues) до крупной
   работы — сверимся, что фича в духе проекта, прежде чем ты потратишь время.

## Карта кода

| Файл | Ответственность |
|---|---|
| `service.py` | FastAPI, endpoint `/session` (SSE), tool-loop, компакция контекста |
| `memory.py` | файловая память, изоляция по каталогу tenant, curator (`supersedes`, append/replace) |
| `tools.py` | схемы инструментов памяти (`recall` / `save_memory` / `load_skill`) |
| `bot.py` | Telegram (long-polling, голос через Groq STT, дебаунс, команды) |
| `skills/` | коучинговые скиллы — модульные `SKILL.md` |
| `docs/` | ресёрч (напр. [сравнение моделей](docs/model-comparison.md)) |

## Хорошие точки входа для контрибьюторов

- **Новая оптика/скилл** — добавь каталог в `skills/<name>/SKILL.md`. Скилл подхватывается
  автоматически через каталог; основной плейбук выбирает 1–3 оптики под запрос.
- **Абстракция STT** — сейчас Groq Whisper захардкожен; вынести за интерфейс (local / OpenAI).
- **Passphrase-режим** (zero-knowledge, ключ на клиенте) — см. threat model в README.
- Багфиксы, опечатки, улучшение доков — всегда welcome.

## Стиль

- **Простота прежде всего.** Никаких фич сверх запрошенного, никакой «гибкости», которой не
  просили. 200 строк, которые ужимаются до 50, — ужимай.
- **Хирургические изменения.** Не рефактори то, что не сломано; подстраивайся под существующий
  стиль, даже если сделал бы иначе. Убирай только тот мусор, что создали твои изменения.
- Соответствуй окружающему коду по неймингу, плотности комментариев и идиомам.

## Приватность и секреты

- **Никогда** не коммить `.env`, `tenants/`, `subscribers.enc`, реальные токены/ключи/chat_id.
  Всё это уже в `.gitignore` — проверь `git status` перед коммитом.
- Не добавляй в трекаемые файлы личные данные (свои или чужие). Примеры — обезличенные.

## Pull requests

- Одна логическая правка на PR; понятный заголовок и краткое «зачем» в описании.
- Проверь, что бот и сервис поднимаются локально, а затронутый путь отработал вручную.
- Если правишь поведение коуча — приложи до/после на нейтральном (не личном) кейсе.

## Дисклеймер

AICOACH — инструмент саморефлексии, не медицинское изделие. Правки, добавляющие обещания
клинического эффекта или диагностики, не будут приняты — см. дисклеймер в README.
